# filexfer — 大文件断点传输库

源文件与传输产物位于本地文件系统，恢复信息保存在 SQLite 中。
分块校验、断点续传、原子发布。

## 能力

- `TransferLibrary.register(source_path, dest_path, manifest)`：登记传输，
  接收源路径、目标路径与可信内容清单（总长度 + 按 64 MiB 顺序分块的
  各块 SHA-256，末块按实际长度）。任务身份仅由清单决定；
  重新打开库后无需再次提供清单。
- `TransferLibrary.run(task_id)`：继续执行。逐块读取源文件、校验摘要、
  写入目标目录下的隐藏暂存文件并逐块落库；读失败或摘要不匹配时抛出
  异常，已确认进度保留，下次调用可重试。全部确认后原子发布。
- `TransferLibrary.status(task_id)`：查询已确认字节数（从文件开头起连续
  校验成功的块，末块例外）与完成状态。

## 保证

- 任务身份绑定登记时的清单；源文件被替换后，仅靠逐块 SHA-256
  重新校验认定内容，不信路径、长度或修改时间。
- 全部内容校验完成前，目标原有文件保留（或保持不存在）；发布通过
  同一目录内暂存文件 `os.replace` 一次切换，不暴露中间内容。
- 全部数据确认后，即使源文件被移走，仍可完成发布。
